# Структура фотографий TravelRusin.ru

Куда класть фото. Имена файлов — **только латиница, без пробелов**.

```
PHOTOS/
├── hero/
│   └── cover.jpg                 # 1 фото на главный экран (большое, горизонтальное)
│
├── about/                        # слайдер на странице «Обо мне»
│   ├── 01-portret.jpg            # портрет Николая
│   ├── 02-na-marshrute.jpg       # на маршруте
│   ├── 03-s-gruppoy.jpg          # с группой
│   └── 04-arhiv.jpg              # архивное фото
│   (можно добавлять 05.jpg, 06.jpg… — попросите подключить)
│
├── tours/<slug>/                 # по папке на каждую экскурсию (9 шт.)
│   ├── cover.jpg                 # ОБЯЗАТЕЛЬНО — обложка (каталог + шапка)
│   ├── 01.jpg                    # фото для слайдера на странице экскурсии
│   ├── 02.jpg
│   └── 03.jpg …
│
├── gallery/                      # общая «Галерея» сайта, по категориям
│   ├── routes/                   # Маршруты
│   ├── old-alushta/              # Старая Алушта
│   ├── architecture/             # Архитектура
│   └── achievements/             # Достижения (дипломы, сертификаты)
│
├── blog/
│   └── <slug>.jpg                # обложка статьи (имя = slug статьи)
│
└── _arhiv/                       # не используется на сайте, на разбор
```

## Папки экскурсий (slug)

| Экскурсия | Папка |
|---|---|
| Знакомство с Алуштой | `tours/znakomstvo-s-alushtoy/` |
| Истории Профессорского уголка | `tours/professorskiy-ugolok/` |
| Алушта: история безуездного города | `tours/bezuezdnyy-gorod/` |
| Рассветная набережная | `tours/rassvetnaya-naberezhnaya/` |
| неВыдуманные истории Алушты | `tours/ne-vydumannye-istorii/` |
| Алушта в кино | `tours/alushta-v-kino/` |
| Краеведческая велопрогулка | `tours/kraevedcheskaya-veloprogulka/` |

| Они сражались за Родину | `tours/oni-srazhalis-za-rodinu/` |

## Важно

- **Обложка** экскурсии всегда `cover.jpg`.
- **Слайдер** экскурсии: добавляете `01.jpg, 02.jpg…` в папку — затем нужно вписать их
  в `public/data/content.json` (поле `gallery`) или через админку. Сейчас слайдеры пустые
  (показывается только `cover.jpg`).
- Новые фото в галерею: кладёте в нужную категорию `gallery/<категория>/` и просите подключить.
- Тяжёлые файлы (>1 МБ) лучше сжать перед заливкой — сайт грузится быстрее.
